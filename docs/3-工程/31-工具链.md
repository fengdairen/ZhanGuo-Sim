# 31 · 工具链

> `tools/` 下 60 个脚本，**大多是历史过程产物**。
> 真正日常要用的只有少数几个，先看"日常"那张表。

## 1. 日常会用到的

| 脚本 | 作用 | 什么时候跑 |
|---|---|---|
| `export_state.py` | `备份.xlsm` → `data/state.json` | Excel 改了之后 |
| `inventory_data.py` | 列出各数据表行数 | 写文档、核对规模 |
| `check_docs.py` | 校验文档相对链接、汇总标题 | 改完文档 |
| `make_map_editor.py` | 生成地图编辑器 HTML | 改了编辑器代码 |
| `make_pop_table_editor.py` | 生成人群库 HTML | 同上 |
| `make_vector_map.py` | 生成矢量地图 HTML | 改了矢量数据 |
| `rivers_from_editor.py` | 描迹 JSON → 矢量河网（水量定宽） | 描完河、改了水量 |
| `sync_river_editor.py` | 导出 JSON → 规范位置 + 随包数据 | 描迹器导出之后 |
| `serve_river_editor.py` | 描迹器本地服务（读 + 自动写盘） | `启动描迹器.cmd` 会拉起它 |
| `smoke_river_editor.js` | 描迹器冒烟测试（桩 DOM，含分段/水量/命名/认父） | 改了描迹器代码 |
| `merge_editor_export.py` | 编辑器导出的 CSV 合并回数据 | 收到编辑器导出 |

构建与校验：

```powershell
$env:DOTNET_CLI_HOME = "<repo>\.dotnet"
$env:NUGET_PACKAGES  = "<repo>\.nuget\packages"
$env:DOTNET_CLI_UI_LANGUAGE = 'en'

dotnet build   src\ZhanGuo.Workbench -c Release
dotnet publish src\ZhanGuo.Workbench -c Release -o dist
dotnet run --project src\ZhanGuo.Verify -- <repo>   # 284 项公式校验，exit 0 即通过
```

| 环节 | 工具 |
|---|---|
| 描迹器本地服务 | `serve_river_editor.py`（`dist\river-editor\启动描迹器.cmd` 会调用） |

## 4. 注意

- `tools/_*.txt` 是脚本生成的报告，**可随时删**，不进版本控制
- `data/map/rivers/_backup/` 是描迹器的自动备份（每分钟一份，留 30 份），**不进版本控制**
- 大量脚本依赖 `ditu.png` / `城池.png` / `城池名称.png` 三个源图（已在仓库根目录）
- `ditu.psd`（298 MB）**不在仓库**，超大，需要时从本地取

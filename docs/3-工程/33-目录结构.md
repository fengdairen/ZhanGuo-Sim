# 33 · 目录结构与整理约定

> 状态：2026-11-13 系统整理。**新增文件前先看这里**，别再往根目录扔。

---

## 1. 一眼看全

```
/
├── 启动数据台.cmd        ← 唯一入口：起本地服务 + 打开数据台首页
├── 重建地图.cmd          ← 出图：四步管线
├── 备份.xlsm            数据模板（只读参考，别改）
├── AGENTS.md / README.md / .gitignore
│
├── assets/              不进版本库的大件
│   ├── source/          七张源图（ditu.png / 城池.png / 底图*.png …）
│   └── ditu.psd         原始 PSD（298 MB）
├── data/                数据（真相）
│   ├── state.json       九国经济/军事/制度
│   └── map/             城邑、部族、人口、归属、经济 + rivers/ 与 vector/
├── dist/                产物（可重新生成）
│   ├── index.html       数据台首页
│   ├── river-editor/    河湖海描迹器
│   ├── map-review/      国界绘制器 / 城池编辑器 / 地名勘误 / 人群库
│   └── map-vector/      矢量舆图
├── docs/                00 入口 + 6 个分区（见 docs/README.md）
├── materials/           用户提供的原始材料（推演风格 / 军事设计）
├── src/                 Core（纯公式）/ Workbench（WPF）/ Verify（校验器）

│   ├── pipeline/        当前在用的 21 个脚本
│   ├── smoke/           3 个冒烟测试
│   └── legacy/          47 个历史脚本（不再维护，留着查证）
```

## 2. 各目录的规矩

| 目录 | 放什么 | 不许放什么 |
|---|---|---|
| `data/` | 权威数据（真值表、描迹数据） | 中间产物、脚本、截图 |
| `dist/` | 可直接打开的产物（HTML / exe） | 源图、草稿 |
| `tools/pipeline/` | **现在还在用**的脚本 | 一次性实验 |
| `tools/smoke/` | 冒烟测试（node 直接跑） | 业务脚本 |
| `tools/legacy/` | 历史脚本，只读不改 | 新脚本 |
| `materials/` | 用户给的原始材料 | 生成的文档 |
| `assets/` | 大件、不进库 | 被代码引用的文件 |
| 根目录 | 两个 `.cmd`、README/AGENTS/.gitignore、七张源图 | 任何新东西 |

**源图已经全部挪进 `assets/source/`**：`tools/pipeline/` 与 `tools/legacy/` 里
`ROOT / "xxx.png"` 的写法已统一改成 `ROOT / "assets" / "source" / "xxx.png"`。

## 3. 整理做了什么（2026-11-13）

| 动作 | 结果 |
|---|---|
| 删掉 OCR 中间产物（`node_crops` / `ocr_tiles` / `todo_crops` …） | 2501 → 115 个文件，释放 **150.7 MB** |
| 七张源图移入 `assets/source/`，代码路径同步 | 根目录再无 PNG |
| 删旧复核套件 `data/map/review/`（瓦片 63.9 MB）、过期打包 zip、`dist/debug.log` | data 67→34.5 MB，dist 45.5→17.1 MB |
| `.dotnet` → `.cache/dotnet` | 根目录只剩 7 个目录 + 6 个文件 |
| 删根目录垃圾（`sea`、`vector`、`debug.log`） | — |
| `tools/` 按用途分三组 | pipeline 21 / smoke 3 / legacy 47 |
| 用户材料归档 | `推演风格/`、`军事设计/` → `materials/` |
| 大件归档 | `ditu.psd`（298 MB）→ `assets/` |
| 入口脚本同步 | `启动数据台.cmd`、`重建地图.cmd` 指向 `tools/pipeline/` |

脚本搬迁时统一改了根路径推导：`parents[1]` → `parents[2]`（smoke 的 `__dirname/..` → `../..`），
整理后**管线与三个冒烟测试全部复跑通过**。

## 4. 新增文件往哪放

| 你要加的 | 放这里 | 顺手做 |
|---|---|---|
| 一次性脚本 | `tools/pipeline/` | 跑完删掉，或挪进 `legacy/` |
| 测试 | `tools/smoke/` | 命名 `smoke_*.js`，node 直接跑 |
| 新文档 | `docs/` 对应分区 | 在 `docs/README.md` 加一行索引 |
| 新数据 | `data/` | 在 `docs/2-数据/20-数据总览.md` 登记 |
| 新产物 | `dist/` | 在 `重建地图.cmd` 或生成器里固化 |
| 大文件 / 原始素材 | `assets/` 或 `materials/` | 加进 `.gitignore` |

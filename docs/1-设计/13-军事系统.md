## 一、结构复述

### 1.1 三层与玩家权限

| 层 | 是什么 | 玩家怎么影响 |
|---|---|---|
| **战斗层** | 一个"队"和另一个"队"互砍 | 只能靠**长期建设**（训练、装备、兵基）间接提升 |
| **战役层** | 军团 vs 军团 | 靠**合理搭配与部署**（阵容、兵种比例、将领） |
| **战略层** | 行军、补给、遭遇 | **手操** |

**关键约定**：计算上，**战斗层属于战役层的一部分**——即战斗层不是一个独立结算层，而是战役层的一个步骤。

这个约定很重要：它意味着我们只需要实现一个 `CampaignResolver`，内部含战斗循环，**不需要两个独立模拟器**。

### 1.2 战役层的数值链

**一级数值**（来源）→ **二级数值**（计算用）→ 战斗判定

```
兵基（北地农户/关中猎户…）
  → 基础攻击 / 基础敏捷 / 基础士气 / 基础控弓 / 基础骑术 / 基础御车

人员情况 → 满编率

装备（兵戈/盾甲/弓弩）
  → 兵戈攻击、防御率、减伤率、盾甲笨重、弓弩对远、齐射次数、后射概率

军团（将领、军团建设）
  → 训练度 / 组织度 / 军团士气

战役（类型、特殊情景）
  → 战斗类型乘数
```

**二级数值（原文公式，逐字抄录）**

| 名称 | 算式 |
|---|---|
| **伤害** | `（基础攻击+兵戈攻击）*（1+训练度^0.5）*（满编率^0.8）` |
| **韧性** | `（（军团士气+基础士气）^0.5）*（1+组织度/100）*（1+训练度^0.2）*（满编率^1.2）` |
| **敏捷** | `（基础敏捷-盾甲笨重）*（1+训练度^0.2）` |
| 减伤率 / 防御率 / 战斗类型乘数 | 直接使用 |
| **预期战斗力** | `基础攻击 × 基础士气`（常数） |
| 已承受伤害 | 初始 0 |

**死亡判定**：`已承受伤害 ≥ 韧性` → 该单位死亡。

**军团士气损耗**：
```
军团士气损耗量 = 初始军团士气 × (死亡单位预期战斗力 / 全军团预期战斗力之和)
```

> 这条是整个设计里最漂亮的一处：**死一个抓来的农夫和死一个魏武卒，对士气的打击不同**。
> 它把"精锐损失"变成了一个自动涌现的量，而不是另设一个"精锐度"字段。

### 1.3 常数表（原文）

| 常数 | 值 |
|---|---|
| 闪避基数 | 10 |
| 夹击乘数 | 0.4（`夹击伤害 = 减伤后伤害 × 0.4^距离`） |
| 纵向补位支援时间 | 2 回合 |
| 纵向补位损耗率 | 0.2（补位单位先吃 `韧性×0.8` 伤害） |
| 骑兵夹击比率 | 0.15 |
| 骑兵组织比率 | 0.02 |
| 军团士气退战比率 | 0.5 |
| 军团士气崩溃比率 | 0.7 |

常数反映的是军队制度与军事科技：训练战术、指挥架构、兵役制度、武备生产、辎重运输、工程建设、军功制度、军纪保障。

### 1.4 一场战役的四轮

```
战前轮（只跑一次）
  ├ 辎重车结营：缩小战宽，损失战斗补给（公式未设计）
  ├ 前排初始化：按预期战斗力降序，中轴线起左右交替填充
  ├ 战车冲阵：不参与布阵，只在此轮冲撞对方前排
  └ 对远齐射：全军一次，大范围高伤害，前后排都会中

战斗轮（循环）
  ├ 近身对砍（前排 1v1）
  ├ 骑兵辅助（侧翼迂回 / 侦查传令，耗马匹耐力）
  ├ 后排对远打击（伤害更低、次数更少）
  ├ 夹击结算（正面无敌军时，左右最近最弱者）
  ├ 纵向补位（后排上前，需 2 回合，带损耗）
  └ 横向补位（向有敌军一侧移动 1 格）

结算轮
  ├ 判定：前排空否
  ├ 判定：连续击溃（两次 → 撤退判定）
  ├ 判定：敌方撤退（士气损耗 > 0.5 则撤）
  ├ 判定：推进（不推进 = 脱战；推进则强制对方被动补位）
  └ 判定：士气与补给（崩溃比率 0.7；补给归零）

战后轮
  └ 按三个常数折损满编率 / 装备 / 军团士气（数值未定）
```

**战场与补位**

- 战斗宽度 n：最宽 12、最窄 4
- 前排被打空 = 一次**击溃**
- 连续击溃两次 → 撤退判定
- 每击溃一次，进攻方可选**推进 or 不推进**（不推进＝脱战）
- 双方都进不了撤退判定 → 两败俱伤

### 1.5 战略层

**军团状态机**：待命 / 驻扎 / 防御 / 行军 / 占领

**战斗类型由"双方状态"决定**（这张矩阵非常干净）：

| 攻方 | 守方 | 战斗类型 | 优势方 |
|---|---|---|---|
| 行军 | 待命 | **突袭** | 攻方巨大优势 |
| 行军 | 驻扎 | **野战** | 对垒消耗士气 |
| 行军 | 防御 | **攻坚** | 守方明显优势 |
| 行军 | 行军（相向） | **遭遇** | — |
| 行军 | 行军（非同向） | **追击** | — |
| 行军 | 占领 | **反攻** | — |

**补给**：就地取（本一级地块）→ 不足则从相邻地块调（额外运输损耗 + 补给迟滞导致战斗力与移速下降）。

### 1.6 四种军团

| 类型 | 特点 | 能否编辑 |
|---|---|---|
| **常备军** | 分中央/地方（调度无差异，中央士气更高），闲时训练也吃补给 | ✅ 可配队配装配将 |
| **征召军** | 农闲动员，战力与组织度低，但便宜、量大、灵活，只有征召时吃补给 | ❌ |
| **族兵** | 封君的私兵，需**透支君主威望**获取；效忠族长而非国君，士气不稳；补给可由封君出（有范围限制且士气更低）或玩家出 | ❌ |
| **蛮兵** | 蛮族附庸的兵，士气取决于与附庸族群的关系；补给同上 | ❌ |

> "族兵需要透支君主威望"这条，和 `6-推演记录/60` 记录的"魏国国策条数因失当而减少"是同一类设计——
> **威望是政治资本，不是数值装饰。**

## 二、与现有项目的对接

### 2.1 好消息：它天然符合铁律

这份设计是**纯模拟器**——全部由数值与公式决定，没有任何一处需要 LLM 介入。
这完全符合"模型不碰模拟器"。

**LLM 在这里的位置只有两个**：
1. 战略层：把玩家的国策文本解析成"某军团 → 某地块"的行动意图
2. 叙述层：把结算结果写成人话（如 `1-设计/11` 的定性层）

### 2.2 需要厘清的三处接缝

**① 兵种维度 vs 兵源维度**

`state.json` 里的军队是**兵种**：步卒 / 甲士 / 骑兵 / 战车（+ 水师）。
这份设计里的四种军团是**兵源制度**：常备 / 征召 / 族兵 / 蛮兵。

> **这两个是不同维度，可以正交组合**：一支"常备军"里可以有步兵、甲士、骑兵、战车。
> 建议：军团 = 兵源类型 + 队的列表（每队有兵种）。

**② "队"的规模未定义**

战斗以"队"为单位（1 队占 1 战斗宽度），但**1 队 = 多少人**没写。
这直接决定数值尺度（伤害、韧性都是对"队"而言）。建议明确，例如 1 队 = 100 人。

**③ "一级地块"与我们的地图对不上**

战略层以"**一级地块**"为调度单位，而我们的地图层是 **1040 个城邑 + 54 部族**，没有"地块"这一概念。

三种可能：
- (a) 一级地块 = 城邑（那样 1040 个格子太碎，行军会变成逐城挪动）
- (b) 一级地块 = 更大行政区（郡/县，需要新做一层）
- (c) 一级地块 = 地图上已有的"关隘/山地/经济地块"三类地块（`6-推演记录/60` [44] 提过）

**这个必须你定**，因为它决定战略层的粒度，也决定地图数据要不要再加一层。

## 三、我查出的问题

分三级：**A 疑似笔误**（改一个字就能修）、**B 表述歧义**（需要你重新定义）、**C 设计缺口**（原文自认或确实没写）。

### A. 疑似笔误（3 处）

#### A1. 近战命中率与远程命中率**自相矛盾**

```
近战：命中率 = min(进攻方敏捷 / (受击方敏捷 + 闪避基数), 100%)
远程：命中率 = min(受击方敏捷 / (受击方敏捷 + 闪避基数), 100%)
```

两处都叫"命中率"，但分子不同：
- 远程那个式子，`受击方敏捷/(受击方敏捷+基数)` **越大代表越容易被命中**——这其实是**闪避率**，不是命中率。命中率应是 `1 - 该值 = 基数/(受击方敏捷+基数)`。
- 近战那个式子用**进攻方敏捷**做分子——那意味着"我方越敏捷，命中越高"，而对方敏捷只起分母作用。

**需要你明确：敏捷到底影响"命中"还是"闪避"？**
我的建议（最省改动）：

```
闪避率 = 受击方敏捷 / (受击方敏捷 + 闪避基数)
命中率 = 1 - 闪避率 = 闪避基数 / (受击方敏捷 + 闪避基数)
```

这样攻方敏捷只通过"谁先出手/伤害"体现，不参与命中，逻辑最干净。
若你希望"快打慢更容易中"，则：`命中率 = 攻方敏捷/(攻方敏捷+受击方敏捷+基数)`。

#### A2. 韧性公式多了一个反斜杠

```
（（军团士气+基础士气）^0.5）*（1+组织度/100）*（1+训练度^0.2）*（满编率\*^1\.2）
                                                                  ↑ 这里
```
Markdown 转义残留。应为 `满编率^1.2`。

#### A3. 战车冲阵的三个概率加起来可能 > 1

```
撞溃 = max(p/2, 0.15)
撞退 = max(p, 0.4)
未中 = 1 - max(p/2, 0.2) - max(p, 0.4)
```

代入 p=0.9：撞溃 0.45、撞退 0.9，两者合计 1.35，超过 1。且"未中"里的 0.2 与"撞溃"里的 0.15 不一致。

**建议改成嵌套式**（撞溃是撞退的子集）：

```
撞溃 = max(p/2, 0.15)
撞退（不含撞溃）= max(p, 0.4) - 撞溃
未中 = 1 - max(p, 0.4)
```
这样三项恒和为 1。

### B. 表述歧义（2 处）

#### B1. 防御率与三档减伤的关系

原文：
> 防御率的 10% 为完美防御，按 减伤率×2 减伤（至多 80%）
> 防御率的 60% 为一般防御，按 减伤率 减伤
> 防御率的 30% 为勉强防御，按 减伤率一半 减伤
> **防御率之外，吃全部伤害**

两种读法：
- (i) 这三档是**绝对概率**，三者之和 = 100%，那"防御率之外"就没地方了
- (ii) 这三档是**防御率内部的比例**：完美 = 防御率×10%，一般 = 防御率×60%，勉强 = 防御率×30%，其余 (1−防御率) 全吃

(ii) 才自洽。**建议在文中明确写成 (ii)。**

#### B2. 战斗轮内部各项的结算顺序

对砍、骑兵辅助、后排对远、夹击、补位——**这五项在一轮里谁先谁后，会显著改变结果**。

建议固定为（从"先发生"到"后发生"）：
```
① 骑兵机动（侧翼迂回/传令）
② 后排对远
③ 前排对砍
④ 夹击
⑤ 纵向补位 → 横向补位
⑥ 数值重算与死亡判定
```
理由：先机动后交火、先远程后近战、最后处理位置变化——这与真实交战节奏一致。

## 四、值得学的三个设计

1. **"预期战斗力"作为权重**
   用它排布阵顺序、算士气损耗、选夹击目标——**一个数三处复用**，不需要再发明"精锐度""重要性"之类的新字段。

2. **战斗类型由双方状态自动决定**
   六种类型的矩阵是穷尽的、互斥的，不需要 LLM 判断"这算什么仗"。**这是把叙事判断转成状态机的典范**。

3. **族兵要透支君主威望**
   把"用私兵"的代价放在**政治资本**上而不是钱上——和 `6-推演记录/60` 的"国策条数"同源，
   说明这套体系里**威望才是硬通货**。

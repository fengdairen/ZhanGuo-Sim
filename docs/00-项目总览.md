## 2. 五层（一句话版）

| 层 | 一句话 | 类别 |
|---|---|---|
| **经济表** | 城池的产出 → 税基 → 收入；工程/军事/行政 → 支出 | 模拟器 |
| **地图层** | 城邑与部族的归属、地形、通道 | 容器 |
| **军事层** | 战斗/战役/战略三层，队→军团→地块 | 模拟器 |
| **政策树** | 制度等级与改革点 | 修改器 |
| **势力层** | NPC 与派系的诉求、底线、态度 | 修改器 |

> **模拟器必须守恒，LLM 绝不能直接写数值；修改器是 LLM 的主场。**

详见 [1-设计/10-五层架构.md](1-设计/10-五层架构.md)。

---

## 3. 五条铁律

1. **模型不碰模拟器**（经济、军事的数值只能由代码写）
2. **M0–M2 不接 LLM**（先用假国策跑通流水线）
3. **Excel 是编辑期工具**，运行期用 JSON/CSV
4. **结算是纯函数**，可回放、无副作用
5. **变更单必须带事由**，不许静默丢弃玩家的话

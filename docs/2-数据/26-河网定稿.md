## 7. 遗留事项（不影响使用）

| 事项 | 说明 | 处理建议 |
|---|---|---|
| **丹水首端压在睢水上（0.0px）但未接** | 接了会从"一级支流"变"岔流·一级支流" | 待用户判断是同源还是误吸 |
| **7 组跨河重名** | 丹水×3、沮水×3、洛水×2、修水×2、沘水×2、泜水×2、雁门水×2 | 先秦同名异河很常见；若实为同一条河需合并 `river` |
| **3 条极短段**（17–22 px） | 芍陂西水道、芍陂东水道、固城-丹阳水道 | 连接件，保留即可 |
| **21 处湖泽无入湖河** | 大野泽、貕养泽、巨淀、雷夏泽、菏泽… | 泽陂类多为封闭水体，正常 |

## 8. 定稿过程中的关键决定

| 决定 | 理由 |
|---|---|
| 位图提取全部废弃，改为人工描迹 | 自动提取的河网错接、重复、把一条河画成两条 |
| **线宽只看水量**，等级只表示"我是谁的支流" | 淮河水量不如长江支流，按等级定宽会画反 |
| 类型自动判定（干流/n级支流/岔流/水道/运河） | 手选容易前后不一致；规则由源头与汇入对象唯一确定 |
| 类型按**整条河**判定 | 分段只是标注习惯，不该改变性质 |
| 湖泽边界支持**多段拼接**（手绘/河段交替） | 大云梦泽就是三段湖岸 + 三段河岸 |
| 海面由**海岸线推导**，不再用位图 | 与岸线严丝合缝，地图零位图依赖 |
| 界面动作自动衔接（收笔切选择、面板动作先切选择） | 手工量很大，每次多点两下就是几百次 |

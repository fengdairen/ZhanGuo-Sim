## 写新文档的规矩

1. **一个主题一份文档**。发现两份讲同一件事，就合并，不要并列。
2. **编号稳定**，移动时改目录不改编号；新增取本区下一个空号。
3. **结论带标记**：`[已证实]` / `[推测]` / `[判读]` / `[待验证]`
4. **状态写在开头**：✅ 基线 / 📄 设计 / 📝 讨论稿 / ⏳ 未做 / 🔴 待办
5. 文档里的**相对链接必须能点开**（`tools/check_docs.py` 会校验）

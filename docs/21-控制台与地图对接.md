# 21 · 数据控制台 ↔ 地图控制器：城池归属对接

> 2026-11-11 完成。目标：**在数据控制台里直接分配城池**，且两个工具共享同一份归属数据。

---

## 一、数据契约：`data/map/ownership.csv`

一层新的地图数据，与 `nodes.csv`（城邑）、`regions.csv`（部族）、`populations.csv`（人口）并列。

```csv
city_id,owner,note
n0000,,              # 未归属
n0001,lu,            # 鲁
n0002,wei,           # 魏
```

| 列 | 说明 |
|---|---|
| `city_id` | 对应 `nodes.csv` 的 id |
| `owner` | **国别 id**（`lu/qi/song/wei/han/zhao/qin/yue/chu`），空 = 未归属 |
| `note` | 备注（暂未使用） |

**为什么存 id 不存中文名**：名字会变（`state.json` 里的 `name` 是有可能改的），id 不会。

初始化：1040 行，全部未归属。

```
搜索[____] 类型[全部▾] 归属[全部▾]  分配到[魏▾] [分配归属] [清除归属] [保存归属] [在地图中打开]
共 1040 座，已归属 0，未归属 1040；当前显示 1040
┌──────┬──────┬────┬────────┬────────┬─────────┐
│ ID   │ 名称 │类型│ 人口万 │  归属  │  坐标   │
├──────┼──────┼────┼────────┼────────┼─────────┤
│ n0001│ 安邑 │ 都 │  22.5  │  （未归属）│ 3576,4208 │
└──────┴──────┴────┴────────┴────────┴─────────┘
```

**能力**

| 操作 | 说明 |
|---|---|
| 多选 | `SelectionMode="Extended"`，Shift/Ctrl 多选 |
| 分配归属 | 选中若干 → 选目标国 → 写入并落盘 |
| 清除归属 | 清空所选 |
| 保存归属 | 手动落盘（分配/清除时已自动保存一次） |
| 在地图打开 | 打开 `dist/map-review/map_editor.html#<选中城id>`，地图直接定位到该城 |

**筛选**：搜索（名称或 id 子串）、类型（都/城/邑）、归属（全部 / 未归属 / 各国）。

## 三、地图侧（HTML，`map_editor.html`）

**新增「城池归属」面板**

- 选中城池（点选 / 框选 / 涂色）→ 下拉选国 → **分配**
- **清除归属**
- **导出 ownership.csv**
- **绑定归属文件**：选一次路径后自动写盘（与人口表同一套机制）

**视觉**

- 已归属的城池：**填充该国颜色**，不透明度 1
- 未归属：空心、不透明度 0.55
- 九国配色固定：鲁/齐/宋/魏/韩/赵/秦/越/楚

**深链**

`map_editor.html#n0231` → 打开即选中并居中该城。控制台的「在地图中打开」就是用它。

## 四、两边怎么协同

```
        ┌────────────────────┐        ┌────────────────────┐
        │  WPF 控制台「城池」页 │        │  HTML 地图编辑器     │
        └─────────┬──────────┘        └─────────┬──────────┘
                  │ 读/写                          │ 读/写
                  └──────────► ownership.csv ◄─────┘
                                   │
                            nodes.csv（只读）
```

**规则**

1. **`ownership.csv` 是唯一真相**，两边都读写它
2. 谁改谁立刻落盘（控制台点按钮即写；地图侧绑定文件后 0.8 秒自动写）
3. **不做实时同步**——改完一边，另一边重新打开或刷新即可
4. 冲突时以**后写入的为准**（文件级），没有合并逻辑

> 这是有意的取舍：实时同步需要长连接/文件监听，复杂度高、收益低。
> 当前是"作者单人编辑"的场景，重开一次的成本几乎为零。

## 五、边界与已知限制

| # | 限制 | 说明 |
|---|---|---|
| 1 | 控制台只管**城邑**（1040），不含 54 个部族 | 部族行在保存时**原样保留**，不会被抹掉 |
| 2 | 没有"历史归属" | 只记当前状态。若要做"某年某城易主"，需加 `since` 列与变更日志 |
| 3 | 没有走变更单 | 归属属于地图层（容器），当前按"编辑期数据"处理，不走 `ChangeSet` |
| 4 | 地图侧的颜色只区分国 | 未区分"敌对占领/己方核心"等细分状态 |
| 5 | 两边都不做校验 | 例如"某个都不属于任何国"不会被提示 |

## 六、下一步可以做的

1. **归属校验**：每国至少有一个都；都城必须在己方；未归属城池数量阈值告警
2. **批量按区域分配**：地图侧涂色已经能框一片，但控制台不能框——可以加"按坐标范围分配"
3. **历史归属**：加 `since_year` 列，支持"BC390 归属"与"BC380 归属"两套快照
4. **和势力层联动**：归属变化 → 势力态度变化（`docs/10` 的势力层）

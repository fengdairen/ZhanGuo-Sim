# 战国演义

一款**单机战国题材文字国策模拟游戏**的工程工作区。

玩家扮演国君，用自由文本写下国策；LLM 把国策解读成结构化变更，落到五个数值层上；结算由确定性代码完成，结果以奏报形式回到玩家面前。

> **AI 负责理解与叙述，代码负责裁决与记账。**

## 立刻可用

**矢量舆图**（河 / 湖 / 海岸全矢量，可缩放，无底图）：

```
dist\map-vector\map.html
```

**地图编辑器**（改名 / 改人口 / 移动标点 / 新增 / 删除）：

```
dist\map-review\map_editor.html
```

**数据工作台**（经济表只读查看 + 变更单写入）：

```
dist\ZhanGuo.Workbench.exe
```

**改数据一律走「变更单」**：选对象 → 选字段 → 填加减量（如邑 +3）→ 写事由 → 加入 → 预览 → 提交。
跨地转移直接支持：魏·中山人 的 3 座邑 → 楚（可自动新建「新附」人群）。
其余页面全部只读。每次提交都会写入 `data/events.jsonl`，带前后哈希。

## 五层模型

| 层 | 性质 | 说明 |
|---|---|---|
| 经济表 | 模拟器 | 人口 → 产值 → 税基 → 税收；工程/军事/行政开支 |
| 地图区 | 容器 | 邑/城/都的归属、道路、关隘、地形 |
| 军事层 | 模拟器 | 部队编制与战场模拟器 |
| 政策树 | 修改器 | 17 项制度 × I–IV 级，本质是先秦制度改革 |
| 势力层 | 修改器 | NPC 与派系的利益、权势、态度 |

## 工作区结构

```
战国演义数据台/
├── 备份.xlsm          原始模板（只读）
├── data/
│   ├── state.json         权威状态（九国经济/军事/制度）
│   └── map/               地图层：城邑、部族、人口、归属、经济
├── dist/              可直接双击的 exe 与 HTML 工具
├── src/
│   ├── ZhanGuo.Core/      纯数据 + 公式（无 UI 依赖）
│   ├── ZhanGuo.Workbench/ WPF 数据控制台
│   └── ZhanGuo.Verify/    命令行公式校验器
├── docs/              00 入口 + 6 个分区（设计/数据/工程/决策/调研/推演）
├── tools/             提取、生成、校验脚本
└── 推演风格/ 军事设计/  用户提供的原始材料
```

## 三条不可违反的规则

1. **模型不碰模拟器**——经济与军事的数值只能由代码写。
2. **M0–M2 不接 LLM**——先用假国策把流水线跑通，否则分不清是谁的错。
3. **Excel 是编辑期工具，不是运行期状态**——运行期用 JSON，结算必须可回放。

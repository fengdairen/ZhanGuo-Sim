## 二、推演风格：九条

### 1. 碎片化单播，一条一发

没有"回合报告"这种整块文本。一次结算被拆成 30–80 条短消息，每条 10–40 字：

> 「今年我们从魏国开始」
> 「魏侯提出自己要亲自拜见"西河学派"」
> 「田文摸不到头脑"西河学派也不是个具体的人，你要找谁呢"」
> 「魏侯解释半天，原来是想给西河学派办个学宫」
> 「但是吴起出走给西河学派造成了毁灭性的打击，以至于办学路上少有人响应」
> 「田文只好复命"暂时办不了，合作意愿极低"」　　—— [646]–[651]

**效果**：读起来像现场直播，不像报表。玩家能看见"自己的话被谁听成了什么意思"。

### 2. 逐国结算，顺序固定

每回合开头一句"今年我们从 X 开始"，然后魏→齐→赵→韩→秦→宋→鲁→越→楚 依次过。
军事单独一节，开头固定是"来军事"或某场战役名。

**这是最值得抄的结构**：它让读者知道"现在轮到谁了"，天然解决了长文本的迷失感。

### 3. 判定只有三种结果：成 / 驳回 / 无效

- **成**：一句话交代，附一个可数的收益（"获得一点相应的改革点"）
- **驳回**：**必须点名是谁驳的、理由是什么**
  > 「"赵章带领中牟军进驻邯郸" 被赵章回绝，"你这不是要逼反我弟吗"」[671]–[673]
  > 「"晋中军前往句注塞驻扎"也被否决：那地方吃不上饭，不打仗就别去那种地方受罪」[674]
- **无效**：连驳回都够不上，直接一句「无效」「废话」[697]–[699]

**驳回比成功写得多。** 这是这套推演的灵魂——**国策不是命令，是提案**。

### 4. 判定标准是"有没有配套机制"（最核心）

这是整份记录里出现频率最高的判定理由，反复出现：

> 「鲁侯说建设平陆郡，虽然啥玩意郡县都没说明白，统计户籍更是要人没人要机制没机制」[921]
> 「鲁国的军事改革立意混乱，前后矛盾，规模庞大，内容草率，而且依赖于大量尚未建立的机制，可以说是执行的一塌糊涂」[1005]
> 「因为缺乏配套的政府机制，完全没有进展」[1010]
> 「军功制改革，赵侯定调太高了、又缺乏相应机制，蒋将都掌握不住，最终收效甚微」[1392]

**翻译成我们的语言**：国策的执行力不是靠"决心"算的，是靠**制度层已有的建设度**算的。
这正是我们"系数总线"里 `execution_discount` 该由什么驱动——**制度等级**。

### 5. NPC 有独立人格，会当众驳国君

角色不是传声筒。典型场景：

> 韩侯设宴想一举扫清严党，埋伏刀斧手，结果：
> 严遂：你没事吧 / 严充：弟啊，是你的意思吗 / 蒋将：舞季，你好像是我的部下啊 /
> 舞季：哦对啊我好像是蒋将一手提拔的 /
> 四人面面相觑，然后开怀大笑　　—— [1890]–[1895]

结果：韩侯滑跪，**国策条数 -1**，严党继续执政 [1902]–[1908]。

### 6. "国策条数"是政治资源，会因失当而缩水

| 事件 | 后果 |
|---|---|
| 魏侯举止失当、险些酿成大错 | 田文收束其权，魏国国策 3→**2 条** [1206] |
| 一段时间后田文放宽 | 恢复 **3 条** [1487] |
| 齐公田和病重 | 齐国明年只有 **1 条** [1439] |
| 韩侯政变失败 | 韩国国策 **-1** [1908] |

**这是很妙的机制**：玩家失误的惩罚不是扣钱，而是**减少你说话的分量**。

### 7. 世界有自己的线，不听玩家的

天气、灾害、天文事件独立推进：

> 「今年的夏雨有些不寻常，雨带从南向北推移，在大陆泽一带停下脚步」[758]–[760]
> 「整整半年，从夏到秋收，魏属中山几乎一滴雨都没下」[761]
> 「蝗灾基于去年干旱裸露的河床，在今年夏天突然肆虐」[826]
> 「今年（bc390）十二月中旬，一颗陨石砸在了栎阳」[502]
> 「沙水会在开局一段时间后淤塞」[58]

玩家只能应对，不能取消。**灾害是"考卷"，不是"惩罚"**。

### 8. 数字克制但具体

不铺开大表，只在关键处甩一个数，且都有对照：

> 「我操，简直巨款——足足四百块巨款呢」[792]
> 「中山军团自己一年都要吃七百」[795]
> 「稷下学宫以 1000 预算、300 每年投资开办了」[1876]

用"军团年耗 700"去对照"拨款 400"，一句话就说明白救灾是杯水车薪。

### 9. 语体：口语、脏话、相声、自我勘误

> 「我操，这他妈啥」「1400 字？」[721]–[722]
> 「哈哈 刚才看鲁国国策昏过去了 现在醒了」[1878]
> 「哦我操看错了，甚至不是赵国援助，是韩国」[804]
> 「再勘误，是赵韩各借 150」[808]

**GM 会当场认错并改判**。这看起来很"不严肃"，但实际效果是：玩家相信这个系统**是可争论的**——而不是一台黑箱。

### 3.2 天下大势（开局）

| 国 | 开局处境 |

| **齐** | 田氏代齐进行中，**不再是简单读条**；一场"大东政治地震"将引爆内政斗争 [98][112] |
| **鲁** | 三桓残破：郈被齐夺、郕成边地、费成孤哨；但迎来契机 [94][97] |
| **韩** | 严党（严遂、严充）把持朝政，系统性腐败；灭郑为头号国策 [676][1905] |
| **赵** | 晋中贵族因易地整合成功；赵侯多病，国策只有 1 条 [626] |
| **秦** | 承认土地私有、允许买卖，命甘龙编成文法（被拒）；与**大荔戎**互贸 [682]–[690] |
| **宋** | 戴族掌权，正搞礼法改革以拔高戴族地位 [1882] |
| **周** | 天子尚在，可册封（田氏代齐靠魏引荐得周天子承认）[661] |

### 3.3 地理：动态的，不是背景板

这是这一版最自豪的设计 [163]：

- **河流会淤塞、改道**（沙水开局后淤塞 [58]；黄河可能改道 [105]）
- **地震、山洪**改变地缘格局
- **黄河渡口**：淇水之后只有五个稳定渡口 [116][118]
- **关隘 / 山地 / 经济地块** 三类地块 [44]
- **经济地块**若不能整块归一国掌控，则**完全无法生产** [45] → 逼玩家思考地缘
- 底图自制，所以**决堤、筑城、改河道都能真实反映** [57]

### 3.4 城邑三级

| 级 | 定义 | 数量（本版） |
|---|---|---:|
| **都** | 人口多、有专门戍卒的关键城市，往往是一国之都 | 30 |
| **城** | 地域影响力强，甚至小国都城 | 61 |
| **邑** | 只是聚落，防御几乎可忽略 | 949 |

[90] —— 这一条与我们已建的数据完全一致。

### 3.5 部族

- 山中部族独立于国家体系（东莱、莱在 BC390 "已不具备国家体系，纯粹是山中部族"）[65]
- 群舒部族、南淮夷等有专门重考 [149]
- 部族可被"封君"化（大荔戎成为秦国世袭封君）[718]

### 3.6 资源（本版清单）

```
草场  犀牛
铜矿  铅锌锡矿  金矿  铁矿
朱砂  盐
玉  玛瑙  绿松石
```

**关键规则**：有资源 ≠ 有收入。必须通过国策把它变成**国营产业**（或私营加税）才能变现 [627]。

### 3.7 卓越技术（六项）

定义："有划时代意义、必然不能普适掌握、透支生产力而有极大提升、需要专业技术团队维护和延续的技术" [132]

**劲弩 / 越剑（精制剑）/ 犀甲 / 铁幕甲 / 墨守 / 提花织机**（最后一项非军事）[133]–[135]

### 3.8 制度：16 目 × 四等

- **8 目军事 + 8 目政治** [142][143]
- 每目分**四等**；另有"**改革点**"表示玩家在该等级之上做了多少成果，作为改革进度指标 [144]

### 3.9 军事：四元体系

**步卒 – 甲士 – 骑兵 – 战车** 四元 [140]；
**水师**与**独立骑兵军团**单独编排，常规军团内的骑兵不是野战骑兵 [138][139]；
弓弩不单列，默认军中自带操作手 [141]。

### 3.10 税制：税种 × 税基

这是本版最独特的系统：

| 规则 | 内容 |
|---|---|
| 普通税收**不可调** | 加税只能**新增一个税种**；降税只能通过税制改革间接实现 [776][777] |
| 税种有**专门用途** | 修芍陂 → 征"水利维护税"，税金直接用于当地，不经国君之手 [35] |
| 税种会**变异** | 对韩战争税 → 战争结束后变"对韩备战税"，减不掉 [35] |
| 税种背后是**既得利益** | 减税会遇到激烈反对 [35] |
| 效率可优化 | 税收效率反映缴税意愿与征收损耗；苛捐杂税效率低（设卡成本高）[781]–[784] |
| 黄宗羲定律 | 并税改革长期加重农民负担，但短期收益实打实 [33] |

### 3.11 国策格式

```
‖ 内政 3 条（赵国 1 条）
‖ 外交（涉及内政的写到内政里，别想偷国策）
‖ 军事（写明所有军队的驻地）
```

[642]；补充：**军事只限行动**，练兵、扩军、重组、改编一律算内政 [644]。

### 3.12 其他设定碎片

- **魏属中山**：不交税，自筹粮草养驻军，但中央要出官员俸禄与军饷 → 纯亏 [632]
- **西河学派**：魏武侯不喜欢，吴起出走后半死不活，兴盛不超过十年 [637]
- **越国水上人**：不定居城邑，以捕鱼为生，住在水边甚至船上 [639]
- **荆王越歌**：越国西征派要角，其"荆王军"是西陲重要力量（中央发钱、他拉人）[640]
- **陈蔡**：单方面给魏国上贡 [633]
- **学宫三型** + 史官机制：反映四种培养文官士族的思路 [2052]

## 四、对我们产品的可迁移点

| 记录里的做法 | 对应到《战国演义》 |
|---|---|
| 判定标准是"有没有配套机制" | `execution_discount` 由**制度层建设度**驱动，不是由决心驱动 |
| 驳回必点名 + 给理由 | 奏报里每条未执行的国策，必须写"谁驳的、为什么" |
| 国策条数随威望增减 | 势力层产出 `edict_quota` 系数，直接影响玩家当回合可下几条 |
| 世界独立推进（灾、天象、河改道） | M2 的事件发生器；灾害是考卷不是惩罚 |
| 逐国结算、固定顺序 | 回合流水线的**输出顺序**（与我们的 11 步时序兼容，是"叙述顺序"不是"计算顺序"） |
| 数字只在对照处出现 | 奏报默认定性，关键处给一个数 + 一个参照物 |
| 当场认错改判 | 系统必须支持"事后修正"，即事件溯源的回滚能力 |

### 和我们当前设计的差异（要注意）

| 项 | 记录里 | 我们 |
|---|---|---|
| 时间线 | BC390 | ✅ 已同步为 BC390 |
| 界面 | QQ 群，GM 手动 | 单机程序 |
| 判定 | GM 人脑 + 常识 | 代码 + 系数总线 |
| 玩家数 | 多人各领一国 | 单人一君 |

## 五、给用户确认的问题

1. ~~**时间线改用 BC390？**~~ ✅ 已确认，全部文档已同步。
2. **"国策条数"要不要进模型？** 这是这套推演最有辨识度的机制，但我们的架构里还没有对应字段。
3. **税种式税制要不要现在做？** `docs/13` 的定额税制与它同源，但记录里的"税种有专门用途、会变异、背后有既得利益"更激进。
4. **世界线事件（灾/天象）的粒度**：记录里是 GM 随手编的（蝗灾、陨石、雨带），我们要不要做成可配置事件表？
